# Real-Data Evaluation Results

This folder is for real-data evaluation outputs only. Real-data outputs must not be written to `evals/results/`, which belongs to the controlled simulated benchmark.

Expected future files:

- `real_kg_only_results.csv`
- `real_llm_only_results.csv`
- `real_text_rag_results.csv`
- `real_graphrag_results.csv`
- `real_summary.csv`

Results stored here should be reported separately from the controlled simulated benchmark because the real-data pipeline introduces different evidence scope, data quality, and uncertainty.
